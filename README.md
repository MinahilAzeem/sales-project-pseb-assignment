# PSEB AI Bootcamp assignment3



This notebook cleans sales records, compares revenue across regions and categories, and writes a separate CSV with updated Books prices and sales tax.



1. Keep the notebook and `sales\_raw.csv` in the same folder.

2. Open `**Assignment-03 Data Quality, Insights \& CSV Operations.ipynb**` in VS Code or Jupyter and select a Python kernel with pandas and matplotlib installed. In Colab, upload `sales\_raw.csv` to the session's working folder and make sure '**sales\_raw.csv**' is in same folder.

3. Choose **Run All**. Part A creates `**cleaned\_sales.csv**` and shows both charts. Part B reads the cleaned file and saves `**sales\_updated.csv**`.
